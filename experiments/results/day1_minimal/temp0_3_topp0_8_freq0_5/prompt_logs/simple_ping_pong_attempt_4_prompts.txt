The main difference between Akka and Rebeca is that Rebeca uses a more declarative style, while Akka uses a more imperative style. In Rebeca, you declare the behavior of an actor (or "reactive class") using message service handlers (`msgsrv`), which are similar to methods in other languages. These handlers specify what should happen when an actor receives a certain message. In contrast, in Akka, you define an actor's behavior by writing code that runs when the actor receives a message.
