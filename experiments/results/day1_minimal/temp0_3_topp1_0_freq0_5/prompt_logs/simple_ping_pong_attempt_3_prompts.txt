Please note that in Rebeca, there is no direct equivalent for Akka's `selfdestruct()`. However, you can achieve a similar effect by not sending any more messages to the rebec. Also, in Rebeca, you need to use `delay(0)` before sending a message to another rebec in the same message server. This is because in Rebeca, all statements in a message server are executed atomically unless there is a `delay` statement.
